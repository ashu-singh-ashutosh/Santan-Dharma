# 🕉️ Sanatan Dharma (सनातन धर्म)

A lightweight, single-page web application dedicated to exploring the history, philosophy, core pillars, and sacred scriptures of **Sanatan Dharma** (Eternal Way of Life).

---

## 📌 Features

- **Single-Page Architecture:** Everything is contained within a clean, single HTML structure for fast loading and seamless navigation.
- **Responsive Layout:** Designed to provide an intuitive reading experience across mobile, tablet, and desktop devices.
- **Interactive Navigation:** Smooth scrolling to distinct sections covering various aspects of Sanatan Dharma.
- **Rich Content Display:** Structured cards, quotes, and sections detailing sacred texts, philosophy, and historical context.
- **Modern Styling:** Clean typography and thematic visual design reflecting authentic cultural aesthetics.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and content layout.
- **CSS3 / Tailwind CSS:** Responsive layout, custom color palettes, and interactive transitions.
- **JavaScript (ES6+):** Smooth scrolling, dynamic theme toggles, or interactive elements.
